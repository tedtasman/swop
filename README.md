# SWOP: Swap with out problems

## Installation
### Default: 

```bash
curl -fsSL https://raw.githubusercontent.com/tedtasman/swop/main/remote-installer.sh | bash
```
*Don't execute code you haven't read or don't trust!*

### Developer:

```bash
git clone https://github.com/tedtasman/swop.git
cd swop
./install
```
